Intel 4090

The smallest CPU imaginable. Originally
coded from Python. No commas needed.

Visit the Python version



How the Python version worked:

The Python version used binary instead of words. Basically,
this project is an interpreter, and has its own version/type of
CPU assembly. It has more registers than the Python one, which basically
makes it better, and the newer version of the old one.

Registers, and functions:

There are a lot of registers, which are:

A
B
AX
BX
AH
BH

Functions:

NOP
HELLO (Used only for switch/case tests)
MOV (Similar to MOV in ASM, usage: MOV [reg] [value/reg])
ADD (Usage: ADD [reg] [reg/value])
SVU (Usage: SVU [reg])
