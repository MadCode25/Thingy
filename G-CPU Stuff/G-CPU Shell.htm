G-CPU Decompiler

Converts .ghex bytecode back into G-CPU assembly.

Bytecode Input (.ghex)


Assembly Output


Terminal

G:\>

Notes:
- Unknown opcodes are shown as comments (;)
- MOV AL strings are re-quoted automatically
- Save to Emulator stores assembly in localStorage as "DecompiledProg"

Terminal Commands:
glang run — run the decompiled assembly
glang run hex — run the raw .ghex bytecode directly
echo <text> — print text
clr — clear terminal
help — list commands
status — show register state from last run
