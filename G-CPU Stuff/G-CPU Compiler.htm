Random Tip: UNKIR is short for "(UNK)NOWN (I)NST(R)UCTION."
Fact: Use DFC to set your text color back to normal.

TinBIOS Interrupts:
0x10 - Print Interrupt
0x11 - Print A's value directly.
0x1A - Request input and store in A.
0x1B - Request input and store in B.
0x0F - Increment A.
What AX is for:
AX is used to set color of the text in BIOS, (all text)
in the format of HEX (Form: 0x123456)
