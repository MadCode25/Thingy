G-CPU Runner

Runs .ghex bytecode and displays program output.

Bytecode Input (.ghex)


Output


Opcode Table

12 = SET
15 = MOV
10 = INT
16 = ADD
17 = SUB
19 = JMP
1 = JZ
4 = JAN
20 = HLT

Register Table

0x0 = A
0xA = B
0x3 = AL
0xF = AX

Status

Ready.

TinBIOS Interrupts:
0x10 - Print AL with AX color.
0x11 - Print A's value.
0x1A - Input to A.
0x1B - Input to B.
0x0F - Increment A.
