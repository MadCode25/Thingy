🧠 What is JF (J Fancy)?




JF (J Fancy) is a transpiled programming language that converts readable,
"fancy" English-like commands into JavaScript.



Instead of writing boring code like:




let x = 5;
console.log(x);



You can write:



conjure x = 5;
manifest(x);




The goal is simple:
make code feel like expressive language while still running as JavaScript.



---


⚙️ How it works




JF doesn't run directly. It:




    
  
  1. Takes your JF code
    2. 
  
  2. Replaces keywords using regex
    3. 
  
  3. Outputs valid JavaScript
    4. 
  
  4. Executes it using eval()
    5.

🧪 Example



conjure a = transmute(request("Enter number:"), int);
conjure b = transmute(request("Enter another:"), int);

manifest(a + b);





This compiles into:




let a = parseInt(prompt("Enter number:"));
let b = parseInt(prompt("Enter another:"));

console.log(a + b);
